# Security

This repository contains recovery and flashing material for router firmware.
Treat all generated images and backups as sensitive.

## Default Passwords

The local build enables Wi-Fi on first boot with:

- SSID: `DecoM4-2G` and `DecoM4-5G`
- Password: `openwrt1234`

This is a convenience default for recovery and first login. Change it
immediately after installation.

Also set a root password immediately:

```sh
passwd
```

## Reporting Issues

For security-sensitive reports, avoid posting private backups, ART data, MAC
addresses, serial numbers, or ISP configuration in public issues.
